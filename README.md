# Awesome Free Developer Tools 🛠️

A curated list of free, browser-based developer tools. No signup, no ads, no nonsense.

## 🔧 All-in-One Tool Collections
- [WebToolsHub](https://www.webtoolshub.online) — 50+ free tools: JSON formatter, JWT decoder, regex tester, image compressor & more. No signup, no ads.
- [CyberChef](https://gchq.github.io/CyberChef) — Encryption, encoding & data transformation

## 📝 JSON Tools
- [FileOnTap](https://fileontap.com/) - Free browser-local File Converter for images and PDFs; no signup and files stay on the device.
- [JSONLint](https://jsonlint.com) — JSON validator & formatter
- [JSON Crack](https://jsoncrack.com) — JSON visualizer
- [JSON Hero](https://jsonhero.io) — JSON explorer

## 🔐 Security & Auth Tools
- [JWT.io](https://jwt.io) — JWT decoder & verifier
- [PasswordsGenerator.net](https://passwordsgenerator.net) — Secure password generator

## 🎨 CSS Tools
- [CSS Gradient](https://cssgradient.io) — Gradient generator
- [Clippy](https://bennettfeely.com/clippy) — CSS clip-path generator
- [Neumorphism.io](https://neumorphism.io) — Box shadow generator

## 🖼️ Image Tools
- [Squoosh](https://squoosh.app) — Image compressor by Google
- [TinyPNG](https://tinypng.com) — PNG/JPG compression
- [Remove.bg](https://remove.bg) — Background remover

## ⏰ Productivity Tools
- [Crontab.guru](https://crontab.guru) — Cron expression editor
- [Regex101](https://regex101.com) — Regex tester & debugger
- [Base64.guru](https://base64.guru) — Base64 encoder/decoder
