# Awesome Free Developer Tools

A curated list of free, browser-based developer tools. No signup or ads required.

## All-in-One Tool Collections
- [WebToolsHub](https://www.webtoolshub.online): 50+ free tools including a JSON formatter, JWT decoder, regex tester, and image compressor. No signup or ads.
- [CyberChef](https://gchq.github.io/CyberChef): Encryption, encoding, and data transformation

## JSON Tools
- [JSONLint](https://jsonlint.com): JSON validator and formatter
- [JSON Crack](https://jsoncrack.com): JSON visualizer
- [JSON Hero](https://jsonhero.io): JSON explorer

## Security and Authentication Tools
- [JWT.io](https://jwt.io): JWT decoder and verifier
- [PasswordsGenerator.net](https://passwordsgenerator.net): Secure password generator

## CSS Tools
- [CSS Gradient](https://cssgradient.io): Gradient generator
- [Clippy](https://bennettfeely.com/clippy): CSS clip-path generator
- [Neumorphism.io](https://neumorphism.io): Box shadow generator

## Image and File Tools
- [Squoosh](https://squoosh.app): Image compressor by Google
- [TinyPNG](https://tinypng.com): PNG and JPG compression
- [Remove.bg](https://remove.bg): Background remover
- [FileOnTap](https://fileontap.com/): Browser-based file converter for images and PDFs. No signup required, and files remain on your device.

## Productivity Tools
- [Crontab.guru](https://crontab.guru): Cron expression editor
- [Regex101](https://regex101.com): Regex tester and debugger
- [Base64.guru](https://base64.guru): Base64 encoder and decoder

Know a great free tool? Open a pull request to add it to the list.
